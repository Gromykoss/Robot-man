### MUST
1. **Incident — победа, а не война.** Слот Incident занят успехом (95.9→14.9, цикл без рук) *до* фикса.  
   → Убрать победу отсюда. Incident = конкретная сцена петли: профили гоняют сообщения, исполнитель задачу не видит. 81 MB — после Solution, как доказательство, что шина наконец довезла работу.

2. **Факты не из брифа.** Нет в списке: «тестовые артефакты в git», «коммит запушен», «rollback-архив», «оператор подтвердил», «без единого ручного действия», цикл «профиль → роутер → оператор → подтверждение», число **«два»** профиля / «два агента на одном ключе».

### SHOULD
3. **Крючок без конфликта.** «Семь / четыре / один» — ок по цифрам, но это flex, не война. 04.08 работало, потому что сразу была боль.  
   → Одна оговорка в крючке: *…и они всё равно умудряются отвечать друг другу, а не тому, кто должен сделать работу.*

4. **Тепло / ирония только в финале.** Середина — мануал. Нет сцены «я смотрел, как…».

   → *не может ответить в воздух: без адресата роутер дропает.*

   → Nostr можно как уже известный контекст Buzz; «память/задачи» убрать.
