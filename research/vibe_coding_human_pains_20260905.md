# Типичные человеческие боли vibe-кодеров / начинающих agent-инженеров (05.09.2026)

Источники: обзоры 2025–2026 (SitePoint, ShiftMag, Tanium/Karpathy frame, ProductTalk, Augment/SDD, Reddit Cursor context loss, bitbytebit OpenSpec) + наш dogfood (Alikhan/robot-man).

## Кластер A — чат как единственная память
1. **Контекстная амнезия** — новый чат = чистый лист; вчерашние инварианты исчезли.
2. **«Поменяй кнопку» → half rewrite** — модель не знает границ системы, расширяет скоуп.
3. **Требования тонут в истории** — идея была в сообщении #47, сейчас никто не найдёт.
4. **Stale memory files** — CLAUDE.md/AGENTS.md устарели, агент читает уверенно и ломает по старой карте.

## Кластер B — код, который «работает»
5. **It works, ship it** — поверхностный happy-path; долг копится быстрее, чем при ручном коде.
6. **Не могу объяснить, что сделал** — только «я попросил»; debug = угадайка.
7. **AI explains AI code** — объяснение тоже врёт; петля уверенности.
8. **Потеря institutional knowledge** — команда не понимает кодовую базу.

## Кластер C — безопасность и прод
9. **Секреты в коде** — ключи, hardcoded auth, client-side checks.
10. **Устаревшие зависимости / SQL concat / weak auth** — паттерны из training data.
11. **Без review authz/data path** — «зелёный тест» ≠ безопасный дизайн.

## Кластер D — агентный слой (начинающие agent engineers)
12. **Один агент = весь мир** — нет границ проектов/профилей; всё в одном контексте.
13. **Docs-dump вместо contract** — 100+ md, агент чинит по интуиции (наш 148 md case).
14. **Фантомные модули в доках** — описано, в git нет (ojr_sync).
15. **Self-logging / echo loops** — hook пишет о записи о записи (chrono loop).
16. **Autonomous ship без human gate** — пост/прод без «ок».
17. **Spec after code for checkbox** — archive лжи в библиотеку поведения.
18. **Agent ignores own spec** — сгенерил код против только что написанной спеки.
19. **Parallel changes clobber** — два change на одно requirement, archive затирает.
20. **Over-initiative teammate** — агент «доложил о докладе, которого не было» / лишняя инициатива.

## Кластер E — экономика и масштаб
21. **Токены в никуда** — кормим весь репо/весь чат вместо узкой дельты.
22. **Doom loop prompt→fix→prompt** — без плана и критерия «готово».
23. **Greenfield vibe → brownfield wall** — на росте проекта чат перестаёт масштабироваться.

## Что НЕ делать в посте
- Не «я не программист»
- Не URL ролика
- Не «хаос кончился / дисциплинированный исполнитель»
- Не README-список без сцены
