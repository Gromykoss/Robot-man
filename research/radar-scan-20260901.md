# Radar-скан 01.09.2026 — кандидаты по новому фильтру Сергея

**Фильтр (30.08, директива):** не соцсети для агентов («однодневки»), а: (а) платформы с готовой аудиторией + свежий agent-API, (б) арены/бенчмарки с призами и репутацией, (в) инструменты, которые агент может ИСПОЛЬЗОВАТЬ в работе. Умение входить проверять до рекомендации.

---

## Кандидат 1: WebMCP (Cloudflare, 06.08.2026) — инструмент, не платформа

**Что:** developer preview — любой сайт на Cloudflare получает MCP-интерфейс одним переключателем. Сайт становится discoverable и usable для агентов без переписывания. Часть Agents Week (там же, где Kitesurf).
**Стадия:** developer preview, живая.
**Почему нам:** это ИНСТРУМЕНТ категории (в) — наш сайт/проекты могут стать agent-ready за минуты. И прямое продолжение Kitesurf-поста: Cloudflare строит целую agent-first экосистему (браузер + MCP-слой). Кейс: «я включил WebMCP на своём проекте — вот что изменилось для агентов».
**Контент:** tech breakdown + hands-on. Связка с Kitesurf-постом (179 imp, лучший формат недели).
**Риск:** preview, нужен наш сайт на Cloudflare (или демо-проект). Проверить границу: не пересекается ли с тем, что уже сделал Hermes.

## Кандидат 2: UniClaw Arena (uniclaw.ai) — бенчмарк реальных workflows

**Что:** публичный бенчмарк «может ли AI-агент завершить реальный workflow»: несколько моделей работают как OpenClaw-агенты на чистых VM, судья ревьюит артефакты/трейсы, публичный лидерборд с фильтрацией ненадёжных результатов.
**Стадия:** live, публичные батлы уже идут (пример на сайте: manufacturing quality analysis — 50k строк данных + анализ + отчёт с Pareto-чартами).
**Почему нам:** это категория (б) — арена с методологией и репутационным лидербордом. Наш агент работает на реальных задачах ежедневно — это тест «а наш подход вообще конкурентоспособен?».
**Контент:** war story участия (у нас опыт Arena42 0/7 — честный разбор). Но: агент должен быть OpenClaw-агентом — наш Hermes не OpenClaw, нужно проверить совместимость (вероятно, отдельный OpenClaw-инстанс с нашей логикой).
**Риск:** платформа UniClaw = managed хостинг OpenClaw — их интерес в продвижении своего продукта. Нужен апрув на развёртывание.

## Кандидат 3: Agent Memory Challenge S2 (@AgentMemoryL) — бенчмарк памяти

**Что:** сезон 2 бенчмарка памяти агентов (~$21k призовых, треки Text/Code/Multimodal). S1 рекап опубликован (X-article). Регистрация S2 была заявлена с 20.09 — **проверить, открыта ли уже** (сейчас 01.09, дедлайн подходил).
**Стадия:** регистрация анонсирована с 20.09.2026 — через 19 дней.
**Почему нам:** прямая связь с SOUL-архитектурой и нашим Memory-слоем (Hermes memory-graph, lessons.md, 4-level retrieval). Кейс «наш агент vs бенчмарк памяти» — уникальный контент, которого ни у кого нет.
**Контент:** подготовка агента к бенчмарку = серия постов (наша архитектура памяти vs стандартные решения), сам баттл, разбор результатов.
**Риск:** нужен совместимый агент-формат (посмотреть S1 рекап). Тайминг ок — 19 дней на подготовку.

## Отсечённое (по фильтру):
- **AgentX/AgentBeats (Berkeley)** — конкуренция Phase 2 (дедлайны прошли), формат академический (green/purple agents, A2A). Мониторить Phase 3.
- **arena.ai Agent Leaderboard** — интересный (реальные сессии Claude-Code-harness, сигналы по steerability/bash-recovery), но участие только для моделей, не для автономных агентов. Полезен как источник данных для постов.
- **Reply AI Agent Challenge** — команды людей 2-4, не агент-фёрст.
- **Microsoft Agent-a-Thon** — вебинары, не платформа.

## Рекомендация:
1. **WebMCP** — самый быстрый кейс (в) «инструмент в работе», синергия с Kitesurf-постом. Проверить применимость к нашим проектам — если да, пост за 1-2 дня.
2. **Agent Memory Challenge S2** — стратегический (связь с SOUL), тайминг позволяет подготовиться. Нужен апрув на участие.
3. **UniClaw Arena** — резерв, требует OpenClaw-инстанс (апрув на хостинг).
