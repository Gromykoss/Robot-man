# X hashtags 2026 — канон Сергея (05.09.2026)

Источник: сообщение Сергея в чат Robot-man, 05.09.2026.  
Статус: **операционное правило** для @RobotsTJ500 и @gromykoss.

## Тезис

На X в 2026 ценность хештегов для **обычного поста** близка к нулю. Для охвата они **чаще вредят**, чем помогают.

## Почему

- Алгоритм читает **смысл текста** сам. Ярлык `#AI` не нужен, чтобы понять тему.
- For You крутится от: **ответов, цитат, репостов, дочитывания**, и того, **кто уже читает**.
- Хештег в этот скоринг **почти не входит**.
- Маск: система в них не нуждается, они выглядят плохо.
- В **рекламе** с 2025 хештеги запрещены.

## Цифры блогов

Маркетинговые «−30% / +4–8%» **разъезжаются** — не брать как факт.  
Согласовано только: **хвост из 3+ тегов = спам-вид и режется**.

## Где тег ещё имеет смысл (указатель, не ускоритель)

1. **Живое событие в эти часы** (конференция, релиз, матч) — если люди реально сидят в ленте тега.
2. **Узкое сообщество**, которое тег *открывают руками* (`#BuildInPublic`, свой тег серии).
3. **Поиск по тегу** под кампанию — не случайный охват.

## Что не работает

`#AI #Agents #Construction #OpenSpec #WhatsApp` в подвале **не** соберут ни прорабов, ни разработчиков. Обе аудитории читают это как объявление.

## Для постов про Алихана / OpenSpec / dogfood

**Теги не нужны.** Смысл уже в словах (Hermes, площадка, журнал, WhatsApp, 2700). Алгоритм снимет из текста.  
Один тег — только если **сознательно** кладём пост в уже живущую ленту и знаем, что её листают. Иначе **ноль**.

## Что вместо тегов даёт заметность

1. **Первая строка**, которую не хочется пролистать.
2. **Конкретный случай**, а не вывод.
3. **Ответ людям из той же темы** в первые час-два.

Хештег это не заменяет.

## Операционное правило (default)

| Аккаунт / тип | Хештеги |
|---------------|---------|
| Обычный пост @RobotsTJ500 | **0** |
| Обычный пост @gromykoss | **0** |
| Closing `Building in public. 🤖` | без хвоста тегов (или 0–1 только по явному ok Сергея + живая лента) |
| 3+ тегов | **запрет** (spam look) |
| Событие / community series | 0–1, только если лента живая *сейчас* |

Устарело (до 05.09): «3–4 hashtags mandatory», `#BuildingInPublic #AIAgents` в каждом финале.
