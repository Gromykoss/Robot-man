### Тон
- Спокойный, прямой, без пафоса и без рекламы.

- Честность без нытья: «Виноват не агент.» / «пока не знаю.» / «режим, не спасение.»
- Ирония сухая, не стендап.

### Запрещённый «ИИ-2023» каркас
❌ «Клин / развилка / три вывода / слой опыта»  
❌ «Как устроено:» + bullet README

❌ «Инновационно / seamless / game-changer»  
❌ Пересказ ролика или tutorial OpenSpec  
❌ Шаблон: hook → 5 болей → решение → CTA  

### Разрешённый каркас (из эталона)
1. Опционально: фильтр аудитории одной фразой («не для… пролистать»).
2. **Сцена/предметы** — два агента, два масштаба (любимый / которого хотел удалить).
3. **Контраст одной парой строк** (сеть ✅200 vs стройка в сообщениях).
4. **Один живой инцидент** (формулировка без ограждения → чуть не стёр).
5. **Цена на площадке** — одна фраза (неверный шаг → дни работы).
6. **Перенос дисциплины** — ТЗ → ПД → экспертиза → **рабочая документация (ревизия в силе)** → изменение **до** работ → **общий журнал** → **исполнительная**. Без списка файлов `CHRONOLOGY.md`, если не просили.
7. **Тот же слой у агентов, другие носители** — завал файлов, новый лист сверху, код без изменения, loop-fix вне журнала.
8. **Автономия vs рулетка** — без полного контроля бардак; полный контроль убивает автономию.
9. **Инструмент как режим, не спасение** (OpenSpec). Финал: «пока не знаю» / время покажет — **без** объявления победы и без «рабочая заметка с площадки, где…».

Стройка **как операционная система документов**, не декор:

- ОЖР = журнал факта  
- исполнительная = факт vs проект  
- завал томов / новый лист сверху = docs mess агента  

Не обязательно bunker/prison каждый раз. Не self-id «я прораб».
