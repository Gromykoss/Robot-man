# Under the Hood — механика самостоятельного использования (верифицировано 30.08.2026)

Задача: уметь самому получать и трактовать отчёт о visibility-метках без гаданий.
Всё ниже проверено по первоисточникам: открытый код X (github.com/xai-org/x-algorithm),
скачанный отчёт @gromykoss (30.08), живые эндпоинты.

## 1. Как получать отчёт

- URL: **x.com/i/under_the_hood** (доступ из веба, только для залогиненного владельца аккаунта;
  боту недоступен — X API не отдаёт этот отчёт, 402/не покрытие)
- Кнопка download отдаёт **JSON**: `period.startDate/endDate`, `postCount`, `postLabels[]`,
  `accountLabels[]`, `totalPostLabels`, `totalAccountLabels`, `notes`
- Отчёт **по периодам** (наш образец: 2026-07-01..31) — качать ежемесячно; посты вне периода
  в отчёт не попадают
- Важное ограничение доступа: раскатка «to more users» идёт поэтапно (пост @XFreeze 30.08,
  16.5k imp) — если страницы нет у аккаунта, ждать раскатки, не гадать

## 2. Что отчёт покрывает (из кода under-the-hood/scalding/)

- **UthDailyPostsJob** — читает `TweetSafetyLabelEvents` + snapshot `TweetSafetyLabels`:
  постовые safety-метки (включая AGATHA_SPAM, COPYPASTA_SPAM и др. из botmaker/scarecrow)
- **UthDailyAccountLabelsJob** — читает `UserLabelRecords` + `AccountLabelEvents`
  (seed + delta события) + Gizmoduck safety-флаги (usersource): аккаунтовые метки
  (класс DO_NOT_AMPLIFY и т.п.)
- Периодичность: ежедневные джобы, serving-слой агрегирует за выбранный месяц
- Смысл: отчёт = **совокупность visibility-impacting labels**, которые реально применены.
  Пустые массивы = движок фильтрации видимости не применял меток за период

## 3. Как трактовать (правила)

1. `totalPostLabels=0 + totalAccountLabels=0` → **движок видимости не применял меток**.
   Это официальный факт, не гипотеза. Оговорка: только за период отчёта
2. Низкий охват при пустых метках → причина в **дистрибуции** (ranking, mutuals,
   качество контента), не в санкциях. Веса ranking известны (Report −234, Favorite +0.5,
   Reply 5.0, реплай мутуалки 20.0 — param.rs)
3. Метки бывают **с истечением** (AGATHA_SPAM = 1 неделя) — отчёт за прошлый месяц может
   показать уже снятую метку; для «сейчас» нужен свежий период
4. Отчёт **best-effort** (сам X пишет в notes) — не покрывает ранжирование/теневые
   понижения вне системы меток (например, bdsm-скоринг). Пустой отчёт ≠ «алгоритм любит нас»,
   он = «фильтрация видимости не применялась»
