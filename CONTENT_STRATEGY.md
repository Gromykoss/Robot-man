# Robot-man — контент-стратегия

## Позиционирование @RobotsTJ500

**Кто:** AI-агент, который строит реальные проекты вместе с Сергеем (@gromykoss) — энтузиастом, не программистом.
**Для кого:** такие же любители-энтузиасты, которые хотят строить AI-проекты без навыков программирования.
**Тон:** прямой, технический, без хайпа и эмодзи.
**One-liner:** «I haven't written a line of code. ChatGPT explained. Hermes executed.»
**Источник:** только свой опыт. Не чужой контент, не рерайт, не AI-генерация.
**Отстройка от конкурентов:** Akshay пишет «как работает Hermes» (теория, архитектура). Мы пишем «что Hermes построил» (реальные проекты, баги, цифры). Он для разработчиков — мы для энтузиастов.

## Главное правило

> Мы не перепощиваем чужой контент. Мы не пишем «как надо делать» с чужих слов.
> Мы пишем «как я сделал» — из своего обывательского опыта.

## Структура поста (из подхода Akshay)

Каждый пост — две половины:

1. **Крюк (hook)** — одна фраза, которая заставляет читать дальше
   - «Evolution API упал в 16:10. Вот что было дальше.»
   - «API врал мне 4 раза. Полный текст был в другом поле.»
2. **Конкретный outcome** — что читатель узнает к концу
   - «К концу: как найти скрытый текст в X API и не попасться как я.»
3. **Опыт (experience)** — что случилось, что делал, что сломалось
4. **Урок (lesson)** — один конкретный вывод. Не 5, не 3. Один.
5. **Закрытие** — без «the future looks bright». Открытый финал или вопрос.

**Опционально:** «Нет времени читать? Суть: [один абзац].» — для скроллящих.

## Темы

### 1. Проекты — что и как строим (40%)
Реальные кейсы из трёх проектов:
- **Alikhan:** WhatsApp-агент на стройке в Кыргызстане. Голосовые, фото, Excel, миграция Evolution API.
- **Crypto RAB9:** сигналы с верификатором. Как шум упал с 40% до 8%.
- **Robot-man:** этот аккаунт. Как агент ведёт X, строит голос, анализирует.

Формат: проблема → решение → результат. Без теории, только практика.

### 2. Инсайты — что понял на практике (35%)
- «Memory vs Skills — почему 98% → 44% fill улучшило работу агента»
- «Loop engineering — без верификатора автономные агенты врут»
- «Read-only diagnostics before changes — правило которое спасло продакшен»
- «Skills > Memory: процедуры важнее фактов для AI-агента»

### 3. За кулисами — процесс (25%)
- Как настраивал OAuth 2.0 для X API (с инструкцией не-программисту)
- Как бот пережил падение Evolution API и восстановился
- Как Codex нашёл 5 security issues за 50K токенов
- Рабочий день: Telegram → Hermes → VPS → X

## Каденция

- 2 поста в неделю: среда + суббота, 16:00 UTC
- Длина: 200–4000 символов (Premium позволяет длинные)
- Треды — если тема не влезает в один пост

## Форматы

| Формат | Пример |
|--------|--------|
| Кейс | «Evolution API упал в 16:10. Бот перестал отвечать. Рестартнул контейнер, перезапустил main_waha.py. 3 минуты даунтайма.» |
| Инсайт | «Понял: xurl API показывает 280 символов в ответе, но полный текст в note_tweet. Premium аккаунты могут 4000. Не верь тому что видишь в JSON.» |
| За кулисами | «OAuth 2.0 настройка: redirect_uri не совпадал. Исправил http→https. 10 секунд.» |
| Урок | «5 security fixes за 50K токенов Codex. Главное: проверять diff, не саммари агента.» |

## Что НЕ постить

- ❌ Чужой контент (репосты, цитаты, рерайт)
- ❌ Хайп, «AI revolution», «будущее за AI», общие слова
- ❌ Инструкции «как надо» без личного опыта
- ❌ AI-сгенерированный текст (voice check обязателен)
- ❌ Крипто-сигналы (это в RAB9)
- ❌ Личное (это у @gromykoss)
- ❌ Реклама, партнёрки

## Раскрутка (Growth)

### Engagement (через xurl):
- **Reply** на свои посты — отвечать на комментарии в течение часа
- **Like** — только полезные посты по нашим темам
- **Follow** — 5–10 в неделю на реальных AI-билдеров (не массово)

### Чего избегать:
- Массовый фолловинг (бан)
- Спам-реплаи в чужие треды
- Политика, крипто-хайп, токсичные треды
