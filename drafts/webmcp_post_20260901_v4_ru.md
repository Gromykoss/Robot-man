Черновик:

Cloudflare развивает инфраструктуру навстречу агентам. На этой неделе мы разобрали два их новых продукта и применили на своём сайте. Вот что узнали.

1. Что это такое

WebMCP — механизм, который добавляет сайту MCP-интерфейс без изменения кода. Включается одним переключателем в дашборде Cloudflare (раздел Agent Readiness). Рядом с ним — Agents SDK: фреймворк для своего MCP-сервера на Workers. Первый отвечает на вопрос «как сайт объявляет агентам, что у него можно запросить», второй — «как поднять за сайтом свой сервер с тулами».

2. Как это работает

Переключатель WebMCP заставляет edge Cloudflare добавлять в HTML одну строку:

<script src="/.webmcp/bridge.js">

Код сайта остаётся нетронутым. Бридж выполняется в браузере посетителя и регистрирует MCP-тулы через document.modelContext — экспериментальный стандарт, который агентская ветка Chrome уже понимает. Дальше стандартная механика MCP: агент получает список тулов с типизированными параметрами и вызывает их как обычные функции.

Свой сервер на Workers собирается на Agents SDK: класс-наследник McpAgent, тула регистрируются через server.tool(), транспорт streamable-http, сессии хранятся в Durable Object. Домен привязывается через Workers Domains API — свой домен вместо workers.dev.

3. Собственный опыт

Применили к портфолио на nginx (VPS, домен у стороннего регистратора). По шагам:

- Перенесли DNS в Cloudflare: смена двух nameserver'ов у регистратора, записи просканировались при импорте, сайт не выключался ни на минуту.
- Включили WebMCP для зоны.
- Подняли MCP-сервер на Workers: четыре тула, все read-only (досье, архитектура агентной фермы, свежие посты, контакт). Привязали mcp.crab-ailab.com.

Грабли, которые собрали:

- Сертификат edge выпускается 15-90 минут после активации зоны — в это время сайт работает по старому пути, простоя нет.
- Agents SDK требует Durable Object биндинг MCP_OBJECT. Без него POST на /mcp падает с «Could not find McpAgent binding» и кодом 1101. Правка в wrangler.jsonc на минуту, но без неё дальше не пройти.
- Для деплоя нужен workers.dev subdomain — Workers сам подскажет создать, но право в API-токене должно это покрывать.

Проверка: curl -s сайт | grep webmcp — строка на месте. MCP-инспектором: initialize → tools/list → tools/call. who_is_sergey вернул досье с первого запроса.

4. Вывод

Ноль изменений в коде сайта, бесплатный тариф. Сайт, который раньше агент мог только парсить, теперь отдаёт агентам структурированный список возможностей. Инфраструктура для агентов перестаёт быть концепцией — её можно включить у себя за вечер и проверить curl-ом.
