## Текст RU

Часть 1 была **пилотом**: один live-контур — construction-site WhatsApp-бот.
148 markdown-файлов → contract index: короткий boot на сессию, domain cards, gate в AGENTS.
Идеи OpenSpec (@0xTab) взяли в духе — не как «поставили CLI и хаос кончился».

### 1) Пилот

На одном боте зафиксировали, что работает:
- обязательный короткий вход вместо «прочитай все docs»;
- deep docs только по маршруту карточки;
- после правки домена — обновить индекс или явно отметить, что обновление не нужно.

Пилот доказал паттерн на одном репо. Этого мало для штаба из нескольких агентов.

### 2) Масштаб на всю команду

Те же правила вынесли **за пределы пилота** — на весь флот агентов.

Не «ещё один README на отдел», а общий операционный контур:
- у каждого профиля — свой AGENTS и точка входа в сессию;
- deep docs — по маршруту (карточка / индекс), не свалка;
- изменения домена — обновить индекс или явно `not needed`;
- орг как система: человек → оркестраторы → отделы + боты + инфраструктура.

Паттерн с одного бота стал **нормой команды**, а не исключением одного проекта.

### 3) Визуализация

Когда правила уже общие, систему стало можно **увидеть**.

**Карта пилота (проект)**  
knowledge_graph: **397 узлов / 610 рёбер** (16.08 было 316/515).  
Obsidian graph-view (`96742a2`): **126** заметок с [[wikilinks]] · canvas **126 узлов / 141 ребро** · GRAPH INDEX.  
Открываешь vault — бот как граф (сервисы, баги, фиксы, таблицы), не папка `docs/`.

**Карта флота (команда)**  
Agent Fleet.d2 v3.1: **19** функциональных блоков, **16** живых ссылок на AGENTS и доки.  
Рендер D2+ELK, SVG, **0** пересечений линий.  
Один кликабельный лист на весь штаб.

Чтобы карты не врали: граф пилота пересобирается каждые **6 часов**;  
индекс ловит дрейф (пример: «14 таблиц ОЖР» → **15**, закрыто в **9** местах).  
Карта без живого цикла снова станет плакатом — как md-свалка без gate.

### 4) Рецепт: отдать агенту или сохранить в закладки

Повторить можно в том же порядке:

1. **Один пилот** — live-репо или бот, не вся компания в первый день.  
2. **Contract index на пилоте** — boot-файл + domain cards + gate «deep docs только через карточку».  
3. **Масштаб на команду** — те же правила в AGENTS каждого профиля; один орг-контур (кто кому, где доки).  
4. **Maps** — `graph.json` + graph-view/canvas + GRAPH INDEX на пилоте; одна diagram-as-code схема флота с живыми ссылками в AGENTS.  
5. **Живой цикл** — пересборка графа по расписанию (у нас 6ч) + gate на дрейф.  
6. **Готово, когда** новая сессия агента стартует с индекса/карты, а не с «прочитай 148 файлов» — и чужой агент может пройти чеклист без устной легенды.

Артефакты по именам:  
`graph.json` · canvas / graph-view · `GRAPH INDEX` · domain cards · `CONTRACT INDEX GATE` · fleet `.d2` + SVG.

Документация, которую не видно, почти не существует.  
Сначала пилот, потом общий режим на команду, потом карты, где узел открывается.  
148 файлов → contract-порядок на флоте → две карты.  
Этот пост можно скормить агенту как ТЗ.
