# Cloudflare для агентов — RU-драфт v1 (29.09, заказ владельца)

## Хук (страх/интерес читателя)
Cloudflare блокирует браузерных агентов на половине интернета — и параллельно строит им собственную дорогу. Конфликт интересов или самый честный ход недели? Разбираем, что они сделали для агентов заBirthday Week.

## Факт-база (верифицировано: X API ридбек + оператор Firecrawl 29.09)

1. **cf CLI** (open beta) — агентский CLI: >3000 операций Cloudflare API (у Wrangler ~280), JSON-first (сжат для агентов), natural-language search, TypeScript-конфигурация (cloudflare.config.ts). Агенты — первоклассные пользователи, не люди.
2. **Forge** (OSS) — CI-пайплайн автогенерации SDK/CLI/доков из OpenAPI; cf — его первый прод-клиент. Agent-facing поверхности не рассинхронизируются.
3. **Kitesurf** (update; запущен в августе) — OSS агентный браузер на Workers со встроенным WebMCP; >730K WPT-сабтестов, рендер в терминале, CDP/Playwright/Puppeteer/MCP-совместимость.
4. **BEACON** — открытый RUM-датасет: миллиарды записей, 10K сайтов, BigQuery. Для нас и наших агентов.
5. **Rust в Workers** (experimental) — нативная компиляция (Emscripten, Tokio).
6. **Voidzero-тулчейн** — Oxc 10x React, Vitest 5 до 50% быстрее, tsgolint 12-18x vs ESLint — ускорение кода, который пишут агенты.
7. Контекст стека: Agents SDK (Durable Objects), AI Gateway, AutoRAG, MCP-интеграции (в т.ч. Zero Trust governance MCP-серверов).

## Конфликт интересов (наш угол, подтверждён нашим dogfood)
- Cloudflare — крупнейший бот-менеджер интернета: их детекция блокирует агентов на сайтах каждый день.
- Одновременно: Web Bot Auth (Ed25519 key directory) — стандарт, который продвигает Cloudflare — в нашем UCP-прогоне Shopify checkout де-факто обязателен, иначе бот-детекция блокирует.
- Схема: та же компания продаёт и блокировку несанкционированных агентов, и санкционированный проход (Web Bot Auth, WebMCP, Kitesurf, cf CLI). Смотрщик бот-фермы строит платную дорогу мимо неё.
- Это не обязательно зло: структурированный допуск лучше DOM-скрейпинга. Но надо понимать, что арбитр доступа и продавец дороги — одно лицо.

## Порядок 1-7
1. Хук: Cloudflare блокирует агентов на половине интернета — и строит им же дорогу. За одну неделю они выпустили CLI для агентов, агентный браузер и датасет. Разбираем конфликт интересов.
2. cf CLI: >3000 операций (Wrangler ~280), JSON-first, TS-конфиг. Агенты — первоклассные пользователи.
3. Kitesurf update + WebMCP: OSS агентный браузер на Workers, 730K+ WPT-сабтестов. Агент не кликает по DOM — сайт сам отдаёт тулы.
4. BEACON: миллиарды RUM-записей в BigQuery, бесплатно — реальная веб-перформанс почва для агентов.
5. Forge: генерация SDK из OpenAPI — поверхности для агентов не рассинхронизируются. Плюс Rust в Workers и Voidzero-тулчейн — код агентов компилируется и тестируется быстрее.
6. Конфликт интересов: Web Bot Auth (Ed25519 directory) в нашем прогоне UCP checkout де-факто обязателен — иначе бот-детекция режет. Арбитр доступа и продавец санкционированного прохода — одна компания.
7. Урок: будущее не «агенты против анти-ботов», а структурированный допуск, где у одной компании и кнут, и пряник. Строите агентов — закладывайте Web Bot Auth/WebMCP-поверхности, иначе останетесь на DOM-скрейпинге за кнутом. Building in public. 🤖
