# RU-драфт v4 — security-audit (по cadence реальных постов: Harden AIF / chrome-agent)

Наш прод-сайт gromykoss.crab-ailab.com аудировал агент — по security-audit от @Cloudflare, source-first, без единого исполняемого запроса. 7 гипотез: 3 confirmed, 4 rejected, ноль эксплойтов.

Скилл (MIT) — та самая отправная точка vulnerability harness Cloudflare, 14.5k звёзд. Шесть фаз: рекогносцировка, поиск по coverage-леджеру, валидация, структурированный вывод, независимая реверификация, отчёт. Ключевое правило: агент, нашедший кандидата, никогда его не проверяет — свежий верификатор получает одну задачу, опровергнуть. Не смог — confirmed, с полной трассировкой по исходнику. Смог — rejected, и отвергнутое тоже идёт в отчёт, с механизмом отказа.

Аудит вел агент-Ревьюэр (в нашем цикле сайт строит один агент, аудирует второй, верифицирует третий). Source-first: live сверен с исходником — расхождение ровно две вставки Cloudflare на edge, ни одной ручной правки на сервере. Без OS-sandbox скилл запрещает себе исполнять код цели: всё, что требовало выполнения, ушло в needs_validation, а не в догадки.

Confirmed, три. Medium: WebMCP-bridge (47 616 байт) инжектится на уровне CF-зоны, а не origin — доставался обоим сайтам зоны, один выключатель закрывает оба. Дашборд показал: Agent Readiness, управляемая beta-фича, включилась сама; решение владельца — оставить как есть, риск принят. Миноры — отсутствующие security-заголовки и robots.txt 404 — закрыты и проверены live.

Rejected, с механизмами: XSS — единственный inline-скрипт работает по хардкод-селекторам, источников атакующего нет; утечка секретов — grep нулевой; CSRF и кликджекинг — форм нет, страницы read-only; email — адрес публичный намеренно.

Honest limits. Без sandbox-исполнения динамические классы — инъекции через рантайм, гонки — за кадром. Два вопроса остались в needs_validation: компонент CF (закрыт владельцем через дашборд) и провенанс bridge.js — upstream или модифицированный, без исходного артефакта не сверить. Граница честная: агент фиксирует, что знает, человек идёт в консоль.

Audit trail живёт в вердикт-файле — каждый вердикт с evidence, каждый rejected с причиной. Security для агентов — это не сканер, а процесс, где вывод обязан пережить чужую проверку.

Building in public. 🤖
