## Костяк истории (hook → fix → lesson)

- **Hook:** «I thought our covers were ugly. The problem was the whole pipeline.» / «We didn't need a better image generator. We needed a better workflow.»
- **Scene:** дашборд-обложки, 7/10, «унылые». Драфт-пост, который жжёт квоты на верификацию до апрува.
- **Incident:** инвентаризация показала: у нас были правильные инструменты, но неправильный выбор под тип контента + один шаблон для всего.
- **Fix:** новый воркфлоу (апрув до верификации), Grok Build CLI для сцен, MoA для текста, матрица инструментов.
- **Pattern:** «унылость» ≠ плохой генератор. Унылость = неправильный процесс. Сначала процесс, потом инструмент.
- **Solution:** конвейер: идея → драфт → апрув → Grok Build + MoA → обложка → проверка → апрув → пост. Скиллы cover-production + обновлённые cover-lessons/infographic.
- **Lesson/checklist:** не выбирай инструмент по привычке; тип контента → инструмент; верификация после апрува (не жги ресурсы); сцена > дашборд; 1-3 слова текста на обложке; проверяй цифры по CHRONOLOGY.
