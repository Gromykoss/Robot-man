Черновик:

Cloudflare продолжает развивать инфраструктуру для агентов. В августе, после Kitesurf (браузер без человеческого слоя), они добавили две вещи, которые закрывают следующий вопрос: как агенту работать с обычным сайтом. Мы попробовали на своём портфолио — получилось. Разбор.

Контекст. Cloudflare за последний год строят агентский слой поверх обычного интернета: Browser Rendering для агентов, Workers как среда выполнения, Agents SDK для MCP-серверов, теперь WebMCP и Agent Readiness. Логика простая: агенты приходят в интернет не как люди, и им нужна своя инфраструктура.

Моё портфолио — обычный сайт: nginx на VPS, HTML. Агент, который приходит на такой сайт, видит разметку и гадает: что это за проект, кто автор, чем занимался, как связаться. Альтернатива — Playwright и кликание по ссылкам как человек: медленно, дорого по токенам, ломается на каждой перерисовке.

Что добавил Cloudflare:

1. WebMCP (Agent Readiness в дашборде). Один переключатель — и edge Cloudflare добавляет в HTML одну строку:
<script src="/.webmcp/bridge.js">
Код сайта не меняется. Бридж живёт в браузере посетителя и регистрирует MCP-тулы через document.modelContext — экспериментальный стандарт, который агентская ветка Chrome уже понимает. Сайт объявляет: «вот что можно запросить, вот параметры».

2. Agents SDK для своей части. Toggle без сервера бесполезен — агентам нужно что запрашивать. Мы подняли свой MCP-сервер на Workers: четыре тула, все read-only (досье, архитектура агентной фермы, свежие посты, контакт). Транспорт streamable-http, сессии на Durable Object. Домен mcp.crab-ailab.com привязали через Workers Domains API.

Грабли, которые собрали по пути — пригодятся, если будете повторять:

- NS-смена у регистратора занимает от минут до часов, сертификат edge ещё 15-90 минут. Сайт в это время работает по старому пути, простоя нет.
- Agents SDK требует Durable Object биндинг MCP_OBJECT. Без него POST на /mcp падает с «Could not find McpAgent binding» и кодом 1101. Правка в wrangler.jsonc на минуту, но проглядишь — будешь читать логи через wrangler tail.
- Для деплоя нужен workers.dev subdomain — Workers сам подскажет создать, но право в API-токене должно это покрывать.

Проверка результата — пять секунд: curl -s сайт | grep webmcp. Дальше MCP-инспектором: initialize → tools/list → tools/call. who_is_sergey вернул досье с первого запроса.

Итог: ноль изменений в коде сайта, бесплатный тариф. Сайт отдаёт агентам то же, что и людям — структурированно.

Строим на публике. 🤖
