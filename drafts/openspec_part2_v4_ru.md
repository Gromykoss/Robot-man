### 1) Сначала — масштаб на всю команду

Те же правила раскатили **за пределы пилота**: на штаб агентов.
Не «ещё один README на отдел», а **один** операционный контур:

- у каждого профиля — свой AGENTS / вход в сессию, не свалка md;
- deep docs — по маршруту (карточка/индекс), не «прочитай всё»;
- изменения домена — обновить индекс **или** явно `not needed`;
- орг как система: человек → оркестраторы → отделы + боты + инфраструктура.

Пилот доказал паттерн на одном боте.
Масштаб — тот же паттерн стал **нормой команды**, а не исключением одного репо.

### 2) Потом — визуализация (то, что видно сейчас)

Когда правила уже общие — имеет смысл **увидеть** систему.

**Карта пилота (проект):**  
knowledge_graph **397 узлов / 610 рёбер** (16.08: 316/515).  
Obsidian graph-view (`96742a2`): **126** заметок с [[wikilinks]] · canvas **126/141** · GRAPH INDEX.  
Открываешь vault — бот как граф (сервисы, баги, фиксы, таблицы), не папка docs/.

**Карта флота (команда):**  
**Agent Fleet.d2** v3.1 — **19** блоков, **16** живых ссылок на AGENTS/доки.  
D2+ELK, SVG, **0** пересечений.  
Один лист на весь штаб — кликабельно, не семь разрозненных схем «от руки».

Коротко, чтобы карты не врали: граф пилота пересобирается каждые **6ч**;  
дрейф ловится индексом (пример «14 таблиц ОЖР» → **15**, **9** правок).  
Сначала дисциплина → потом картинка. Иначе картинка гниёт как md-свалка.

### 3) Рецепт: скормить агенту / в закладки

Повторить = **тот же порядок**, не наоборот:

1. **Один пилот** — live-репо/бот, не вся компания в день 1.  
2. **Contract index на пилоте:** boot-файл + domain cards + gate «deep docs только через карточку».  
3. **Масштаб на команду:** те же правила в AGENTS каждого профиля; один орг-контур (кто кому подчиняется, где доки).  
4. **Только после этого — maps:**  
   - graph.json + graph-view/canvas + GRAPH INDEX на пилоте;  
   - одна diagram-as-code схема флота (D2/ELK…) с **живыми** ссылками в AGENTS.  
5. **Живой цикл:** пересборка графа по расписанию (у нас 6ч) + gate на дрейф.  
6. **Готово, когда:** новая сессия агента стартует с индекса/карты, а не с «прочитай 148 файлов»;  
   чужой агент по этому чеклисту может воспроизвести шаги без вашей устной легенды.

Артефакты по именам:  
`graph.json` · canvas / graph-view · `GRAPH INDEX` · domain cards · `CONTRACT INDEX GATE` · fleet `.d2` + SVG.

Честный минус: визуализация **до** масштаба даёт красивый скрин и старую кашу в соседних профилях.  
Мы сделали наоборот: пилот → команда → карты.

Документация, которую не видно, почти не существует —  
но и карта без общих правил почти не существует.  
148 файлов → общий contract-порядок на флоте → две карты, где узел открывается.  
Пост можно отдать агенту как ТЗ: **не рисуй первым, стандартизируй, потом визуализируй.**
