## 2. Сравнение Grok Build vs FAL (тест 01.08.2026, shadowban cover)

| Критерий | Grok Build CLI | FAL (FLUX 2 Klein) |
|----------|---------------|---------------------|
| Текст «0 results» | ✅ верный | ⚠️ риск опечаток |
| Текст «automated label» (multi-word!) | ✅ верный | ❌ обычно портит |
| Стиль по брифингу | ✅ tech-noir точно | ✅ тоже может |
| Файл локально | ✅ PNG 1280×720 сразу | ⚠️ URL → надо скачивать сразу |
| MCV-оценка | 10/10 (vision_analyze) | зависит от итераций |
| Стоимость | токены Grok | токены FAL |

**Вывод теста:** Grok Build CLI — минимум на уровне FAL, а по тексту (multi-word labels) — ЛУЧШЕ. Один прогон вместо цикла из 5+ итераций FAL.

## 4. Что НЕ доступно

- ImageMagick (можно поставить: `apt install imagemagick` / `pip install wand`)
- Прямой API xAI image (Grok Build использует свой OAuth; у Hermes своего ключа нет)
- DALL-E/OpenAI images — нет активного ключа
- Иные внешние генераторы (Midjourney API и т.п.) — нет ключей

## 5. Пробелы / гипотезы для анализа

1. **«Унылость»** — вероятные причины: FAL-цикл даёт абстракции без плотности; dashboard-шаблон один и тот же для всех тем; нет вариативности макетов.
2. **Grok Build image gen** — новый инструмент, протестирован 1 раз. Надо замерить на 3+ темах и сравнить с FAL.
3. **Гибридный пайплайн** (гипотеза): Grok Build генерит сцену+текст → Pillow доклеивает маскота → MCV. Или HTML/CSS для дашбордов, Grok Build для сцен.
4. **Методика** — нужен документ: какой тип обложки под какой тип поста (war story / skill curation / insight / архитектура), с матрицей выбора инструмента.
