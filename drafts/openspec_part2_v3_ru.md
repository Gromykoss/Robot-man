## Текст RU (в чат)

Часть 1: на **одном** живом проекте (construction-site WhatsApp-бот) мы перестали держать систему в куче markdown и собрали contract index — слои, карточки, точка входа.

Часть 2: пилот **не** остался в одном репо. Сначала визуализировали **его**. Потом тот же принцип раскатили на **всю команду агентов**.

### 1) Пилот → карта проекта

На пилоте knowledge_graph дорос до **397 узлов / 610 рёбер**
(16.08 было 316/515; в графе: events, bugs, fixes, db_table, bots, api-quirks…).

В Obsidian (коммит `96742a2`):
- **126** заметок с [[вики-связями]]
- canvas **ALIKHAN GRAPH**: **126** узлов / **141** ребро
- **GRAPH INDEX** — кликабельный указатель (проект, сервисы, боты, баги, фиксы)

Открываешь vault — конструкция пилота видна как карта, а не как папка «docs/».

### 2) Раскатка → карта флота

Тот же ход на весь штаб: **Agent Fleet.d2** (v3.1) —
**19** функциональных блоков, **16** живых ссылок на AGENTS и доки.
Рендер D2+ELK: SVG, **0** пересечений линий.
Человек → оркестраторы → отделы + боты + инфраструктура — **один** лист на команду, не семь разрозненных README.

Пилот доказал паттерн на одном контуре. Флот — тот же паттерн на орге.

### 3) Чтобы карта не врала (коротко)

Граф пилота пересобирается каждые **6ч**.
Индекс ловит дрейф: «14 таблиц ОЖР» → **15**, закрыто в **9** местах.
Карта без пересборки — плакат. С пересборкой — рабочий контур.

### 4) Рецепт: что скормить своему агенту (bookmark / copy-link)

Если хочешь повторить — не «вдохновляйся», а **дай агенту этот чеклист**:

1. **Выбери один пилотный контур** (один живой бот/репо), не весь мир сразу.
2. **Свалку md → contract index:** короткий boot-файл (у нас PROJECT_MEMORY_GRAPH / graph entry) + доменные карточки + правило: глубокие доки только через карточку.
3. **Собери knowledge graph** из фактов системы (узлы: сервисы, баги, таблицы, боты…) → `graph.json` с рёбрами, не «красивая картинка без данных».
4. **Выгрузи graph-view:** заметки с `[[wikilinks]]` + canvas + GRAPH INDEX (оглавление, по которому кликают).
5. **Поставь живой цикл:** пересборка графа по расписанию (у нас каждые 6ч) + gate «после правки домена обнови карточку/граф или явно not needed».
6. **Только после пилота — флот:** одна diagram-as-code схема команды (D2/ELK или аналог) с **живыми** ссылками в AGENTS каждого профиля. Сначала один контур, потом org chart.
7. **Критерий готовности:** агент новой сессии стартует с карты/индекса, а не с «прочитай все 148 файлов». Дрейф цифр ловится сверкой с git, не интуицией.

Артефакты, которые стоит иметь по именам (чтобы агент искал/создавал):
`graph.json` · graph-view / canvas · `GRAPH INDEX` · domain cards · `CONTRACT INDEX GATE` в AGENTS · fleet `.d2` + SVG с линками.

Минус честно: без пересборки и gate карта гниёт так же, как md-свалка. Пилот дешевле, чем сразу «нарисовать всю компанию».

Документация, которую не видно, почти не существует.
Пилот сделал её видимой на проекте. Флот — на команде.
148 файлов, которые никто не открывал → карты, где узел можно открыть — и чеклист, который можно отдать агенту.

Building in public. 🤖
