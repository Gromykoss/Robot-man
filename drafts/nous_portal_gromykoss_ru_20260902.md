Я запускаю целую фирму AI-агентов на Hermes Agent — бота стройки, X-аккаунт, краулеры. Вопрос, который мне задают чаще всего: «во сколько это обходится?»

Раньше честный ответ был некрасивый: ключ OpenRouter, ключ Anthropic, отдельный баланс под Firecrawl для поиска, отдельный под FAL для картинок, ключ OpenAI для озвучки, браузерный аккаунт для автоматизации. Шесть подписок, шесть панелей, шесть мест, где кончаются деньги в три ночи.

Сейчас всё это — одна подписка: Nous Portal.

Что внутри:

— 300+ frontier-моделей одним счётом: Claude Opus 4.7, GPT-5.5, Gemini 3, DeepSeek V4 Pro, Grok 4.3, Kimi, GLM. Переключение модели — одна команда /model в середине сессии, без новых ключей и без «zero-balance» сюрпризов.

— Tool Gateway: пять инфраструктур под одним логином. Поиск (Firecrawl), генерация картинок (FAL — девять моделей от FLUX до Nano Banana Pro), озвучка (OpenAI TTS), облачный браузер (Browser Use), серверлесс-терминал (Modal). Без каждого из этих аккаунтов по отдельности.

— Ни одного ключа в .env: один refresh-токен, из него на каждый запрос минтится короткоживущий JWT. У меня на сервере агентов credential-хигиена стала скучной — в хорошем смысле.

Настройка — одна команда: hermes setup --portal. OAuth в браузере, выбор модели, готово — hermes chat работает сразу.

Честная деталь: собственные модели Nous (Hermes 4) в Portal дешёвые, но для агентной работы их сам Nous не рекомендует — они про chat и reasoning, не про быстрый tool-calling цикл. Для агента бери Claude Sonnet 4.6, GPT-5.5 Pro или DeepSeek V4 Pro. Это редкость — вендор, который прямо говорит «не используй нашу модель для этого».
