Hermes Agent — опенсорсный агент от Nous Research. За полгода набрал 214k звёзд на GitHub. Хоть кто-то в этом зоопарке делает работающую вещь, а не презентацию.

Кто они. Nous Research — американская лаборатория. Тренируют open-weight модели и выкладывают веса. Флагман Hermes 4 — 14B/70B/405B с гибридным reasoning, 405B на Llama 3.1 базе (август 2025).

Но модели — это скучная половина. Вторая, инженерная: DisTrO. Их оптимизатор, который снижает меж-GPU трафик при обучении в тысячи раз. Зачем это нужно: обычный кластер стоит как самолёт. На DisTrO они подняли Psyche — peer-to-peer сеть, где 40B модель тренировали на GPU добровольцев через интернет. Люди просто отдавали видеокарты. Работало.

Hermes Agent — их агентский фреймворк. MIT, один CLI. Что внутри, без маркетинговых слов:

Learning loop — агент сам пишет себе скиллы из твоих действий и сам их улучшает. Память между сессиями — полноценный поиск по всей своей истории, а не «резюме» в промпте.

20+ платформ из одного gateway: Telegram, WhatsApp, Discord, Slack, email, Matrix. Шесть терминальных бекендов: локально, Docker, SSH, Modal, Daytona. Модель — любая из 200+, без правки кода.

Delegation — изолированные сабагенты на параллельные задачи. Tool Calling сворачивает многошаговые пайплайны в один вызов.

Ведущий разработчик Hermes Agent не имеет CS-образования. Значительную часть кода агент написал сам, учая своего автора. Основатель Quesnelle подтвердил в интервью как факт.
