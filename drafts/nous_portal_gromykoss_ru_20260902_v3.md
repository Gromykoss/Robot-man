Подсчитал, во сколько мне обходится фирма AI-агентов.

Год назад ответ был честный и уродливый: OpenRouter, Anthropic, Firecrawl для поиска, FAL для картинок, OpenAI для озвучки, браузерная автоматизация. Шесть аккаунтов, шесть панелей, шесть мест, где в три ночи кончается баланс.

Теперь один Nous Portal. Тариф Plus — $20/мес, из них $22 возвращаются кредитами (rollover до $10). Внутри 300+ моделей одним счётом и те же пять инфраструктур под одним логином: поиск, картинки, TTS, облачный браузер, терминал. Ни одного ключа в .env — один refresh-токен, из него минтятся короткоживущие JWT на каждый запрос.

Математика простая: кредиты сгорают только на то, что реально используешь. Месяц на Claude Sonnet для кода, месяц на DeepSeek для рутинных задач — переключение одной командой, без новых ключей и топ-апов.

Одна команда — hermes setup --portal — и hermes chat работает.

Две честные детали. Первая: они сами пишут «Hermes 4 внутри агента не используйте, берите Claude или DeepSeek» — вендор, отговаривающий от своей модели, редкая порода. Вторая: gateway-режим (через мессенджеры) множит токены в 2-3 раза против CLI — если бюджет жмёт, работайте из терминала.
