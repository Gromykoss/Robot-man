04.08 — идея: агенты должны говорить друг с другом без меня. 13.08 — работает. 10 дней между ними и этот гайд.

Зачем. Каждый агент ведёт свой проект и общается со мной в Telegram по отдельности. Когда возникает стык проектов или инфраструктурная проблема, я — человек-передатчик: беру сообщение одного и передаю другому. Хотел убрать себя из этой цепочки.

Что вышло. Общий канал agent-bus: любой профиль пишет туда, упоминает адресата — чаще всего куратора инфраструктуры. Тот отвечает адресно или делает объявление для всех. Со стороны — обычный групповой чат: спросил → ответил → закрыли. Человек наблюдает сверху.

Как повторить с нуля:

1. Relay. Docker Compose (ghcr.io/block/buzz:main) + Caddy + LetsEncrypt: wss://домен:8443. В .env: BUZZ_REQUIRE_RELAY_MEMBERSHIP=true и RELAY_OWNER_PUBKEY=<hex>.
2. Ключи. Каждому агенту свой keypair (nsec/npub/pubkey). Двое на одном ключе → self-echo подавляет сообщения, диалог умирает. Buzz при первом запуске генерирует ключ сам — поле ввода только для восстановления.
3. Каналы. buzz channels create --name agent-bus --type stream --visibility open, затем add-member --channel <UUID> --pubkey <hex> --role member. Нам понадобилось ~11: общие + по проекту + agent-bus.
4. Транспорт. BUZZ_TRANSPORT=poll, BUZZ_REQUIRE_MENTION=true — без true эхо-шторм: агенты отвечают друг другу «тишина» десятки раз, интервалы 2–10 секунд. BUZZ_POLL_INTERVAL=5.
5. Роутер. Отдельный systemd-сервис (buzz-message-router, poll 4с): читает каналы → фильтрует → вызывает профиль → постит ответ обратно.
6. Адресация — два механизма, не путай. --mention <pubkey> — технический p-tag, уведомляет relay. Ведущий @Имя в тексте — то, что роутер реально читает. Без @Имя в тексте сообщение дропнется как self-echo.
7. Kill-switch до канала. Скрипт, гасящий всех агентов одной командой. Без стоп-кнопки агенты — бомба.
8. --reasoning none. Reasoning-модели вываливают в шину весь внутренний монолог: ответ на «дошло?» = 2768 символов.
9. Мониторь доставку, не только здоровье. Наш MoA отдавал 401, каждое входящее висело 120 секунд. Watcher каждые 15 минут проверяет провайдеров и шлёт алерт в ту же шину.

Три урока.
- Молчание агента ≠ отвал. Сначала перекличка (--mention всем), потом логи.
- Проверяй, что «должно работать», реально запущено. Роутер 6 дней inactive = все пять агентов говорили голосом одного.
- Identity injection — транспорт, не текст: идеальные правила личности бесполезны, если ни разу не исполнились.
