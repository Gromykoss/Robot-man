**Продолжение сериала:** Kitesurf (30.08) → WebMCP (01.09)

Черновик:

Любому сайту — MCP-интерфейс одним переключателем, без единой правки кода. 6 августа Cloudflare выкатил WebMCP, вчера я включил его на своём портфолио и подцепил к нему собственный MCP-сервер. Разбор того, что это меняет на практике.

Сначала проблема. Моё портфолио — обычный сайт для людей: nginx на VPS, HTML, картинки. Агент, который приходит на такой сайт, видит разметку и гадает: что это за проект, кто автор, чем занимался, как связаться. Альтернатива — отдать агенту Playwright и пусть кликает по ссылкам как человек. Медленно, дорого по токенам, ломается на каждой перерисовке.

WebMCP — это не браузер и не парсер. Это способ объявить сайтом: «вот что у меня можно запросить, вот параметры». Спецификация живёт в браузере (экспериментальный WebMCP уже в Chrome), а Cloudflare сделали включение вопросом одного клика.

Что я сделал по шагам:

1. Перенёс DNS домена в Cloudflare. Сменил два nameserver'а у регистратора — всё. Записи Cloudflare просканировал сам при импорте, мне осталось только подтвердить. Сайт не выключался ни на минуту.

2. Включил WebMCP — один переключатель в дашборде (Agent Readiness). Cloudflare на своём edge добавляет в HTML одну строку:
<script src="/.webmcp/bridge.js">
Код сайта не трогаю вообще. Бридж живёт в браузере посетителя и регистрирует MCP-тулы через document.modelContext — стандарт WebMCP, который агентская ветка Chrome уже понимает.

3. Toggle без сервера бесполезен — агентам нужно что запрашивать. Поднял свой MCP-сервер на Workers: четыре тула, все read-only (досье, архитектура агентной фермы, свежие посты, контакт). Транспорт streamable-http, сессии на Durable Object. Привязал к mcp.crab-ailab.com через Workers Domains API — свой домен, не workers.dev.

Проверка занимает пять секунд: curl -s сайт | grep webmcp — если строка есть, агенты увидят интерфейс. Дальше MCP-инспектором: initialize → tools/list → tools/call. Мой who_is_sergey вернул досье с первого запроса.

Что это меняет. Раньше агент на сайте — это парсер, который угадывает структуру по HTML и ошибается. Теперь — клиент протокола: список доступных тулов он получает явно, параметры типизированы, ничего выдумывать не нужно.

Грабли, на которые наступил, чтобы вы не наступили:

- NS-смена у регистратора занимает от минут до часов, сертификат edge ещё 15-90 минут — сайт в это время работает по старому пути, простоя нет.
- Agents SDK требует Durable Object биндинг MCP_OBJECT — без него POST на /mcp падает с «Could not find McpAgent binding». Пишется в wrangler.jsonc за минуту, но проглядишь — будешь ловить 1101 и читать логи через wrangler tail.
- Workers Subdomain — право в токене называется не так, как ожидаешь. Без subdomain деплой не проходит: Workers сам просит его создать.

Итог: ноль изменений в коде сайта, бесплатный тариф. Сайт отдаёт агентам то же, что и людям — структурированно.

Строим на публике. 🤖
