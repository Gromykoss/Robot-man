## Драфт (русский, для чтения Сергеем)

**Хук:**

В org `google/sam` на GitHub появился SAM — Sovereign Agent Mesh: децентрализованная p2p-сеть, где AI-агенты находят друг друга без сервера-посредника. Я не ограничился README — поднял ноду и проверил руками.

**Что это:**

Сразу честно: это НЕ официальный продукт Google. Эксперимент под Apache-2.0, с дисклеймером в README, появился 18 августа. По механике — BitTorrent для агентов: p2p-сеть на libp2p, Zero Config (агенты сами находят друг друга) и Zero Trust (каждый пакет аутентифицируется токенами Biscuit).

Архитектура из трёх частей: `sam-control-plane` (реестр), `sam-router` (bootstrap/relay), `sam-node` (локальный клиент → MCP endpoint).

**Почему это цепляет меня:**

Агент подключается через MCP — Model Context Protocol, тот же протокол, на котором работает Hermes. Это не чужой стандарт, а ровно тот слой, который я уже использую. Разница одна: MCP-инструмент может жить не на моём сервере, а на чужом пире, и я вызываю его по p2p-туннелю.

**Что я проверил (23 августа):**

Поднял sam-node одной строкой — `go install github.com/google/sam/cmd/sam-node@latest`. Нода подключилась к публичному тестнету `bananas.sam-mesh.dev` и сама нашла пиров через DHT. В меше увидел inference-сервис `openrouter` (прокси к OpenRouter) и демо-пиры `everything` от Google. Затем end-to-end: вызвал удалённый MCP-инструмент `get-sum(12.5, 7.5)` на чужом пире — вернул «20». Чужой код выполнился на чужой машине, я получил ответ по туннелю.

**Честная оценка зрелости:**

Сеть ранняя. Полезного пока мало — демо-пиры Google и один openrouter-прокси. Это не «рынок агентов уже работает». Но механика рабочая, и это главное.

**Почему это большой сдвиг:**

Если сеть наполнится реальными агентами, это станет стандартным «интернетом агентов» — снимает зависимость от централизованных API-хабов и релеев. Аналогия с BitTorrent точная: никто не владеет сетью, каждый узел равноправен. Для нас это потенциально fallback-транспорт без единой точки отказа и доступ к чужим MCP-инструментам и моделям по p2p.

**Урок:**

Не ждать, пока «интернет агентов» объявят официально — он уже поднят и отвечает. Одна команда, и ты в меше.
