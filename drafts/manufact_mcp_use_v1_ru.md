# Драфт RU v1 — mcp-use / Manufact («даёт, но не достаточно»)
2026-10-05 · угол: честная оценка полезности, без противопоставления нашим проектам
Факты: research/manufact-mcp-use-research-20261005.md (первоисточники + dogfood §9)

---

**1. Что это.** Собрал MCP-сервер чужим SDK за вечер — и понял, где SDK кончается. mcp-use (авторы Manufact, YC S25, seed $6,3 млн) снимает обвязку протокола: тула с типизацией, интерактивные панели прямо в чате ChatGPT/Claude, инспектор трафика. ~10,7 тыс. звёзд, 41 тыс. загрузок в неделю — но две грабли съели полдня, а под сервером остаётся твоя механика.

**2. Механика.** MCPServer-объект: инструменты объявляются со схемой входа и выхода (zod), Views в React рисуются как ответ инструмента. Запуск — через HTTP-листнер или mcp-use dev; отладка в браузерном инспекторе; облачная часть добавляет хостинг, логи, кросс-клиентские проверки.

**3. Наш прогон.** Собрали демо-сервер с двумя живыми тулами (последние посты из лога публикаций, статистика базы знаний — 494 записи / 475 связей), подняли HTTP-MCP на localhost:3000, подключились клиентом, оба тул-колла прошли. SDK действительно съедает обвязку: один файл вместо десятков строк протокола.

**4. Confirmed.**
- Сборка сервера: npm-пакет, 51 зависимость, рабочий обработчик за один файл; initialize → tools/list → call — стандартный контур без единой самописной строки протокола.
- Инспектор и типизация — реально удобные: ошибки схемы ловятся до рантайма.
- Views как ответ тула — интересный ход: интерфейс продукта живёт внутри чата, отдельный UI не нужен.

**5. Rejected (что выбрали не для нас).**
- Облачная часть: приватный контур со сессиями аккаунтов в чужой хостинг не отдаём; Inspector ведёт трафик на их серверы.
- Кластер Versions: 1.4.2/1.4.3 пакета исторически помечены как malicious (реестр OSSF) — установка только с пиннингом версии.

**6. Honest limits.**
- TypeScript-first. Python-ветка есть, но заметно беднее — стык с питон-стеком идёт через HTTP-транспорт, а не через SDK.
- SDK покрывает «как объявить и поднять», но не «как достучаться»: транспорт до целевого сервиса, лимиты, анти-бот — всё своё.
- Две мелкие преграды в полдня: top-level await требует "type": "module"; выход тула со схемой обязан нести structuredContent — иначе validation error при вполне валидном текст-ответе.
- Стандарт развивается быстрее документации: protocolVersion 2025-06-18, часть доков расходится с кодом 2.7.3.

**7. Итог.** mcp-use экономит самые понятные часы — обвязку протокола, схему, отладку. Дальше начинается твоя собственная механика, и там библиотека не помощник. Полезно как фундамент; недостаточно, если под инструментом стоит живой сервис с капчами и лимитами.
