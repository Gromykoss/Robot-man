# Cloudflare для агентов — RU-драфт v3 (масштаб + удобство, 02.10)

## 1. Хук (страх читателя)
**1.** Больше половины трафика сайтов на @Cloudflare — уже автоматический (данные Radar). Пока одни спорят, придут ли агенты на их сайты, Cloudflare достроила полный стенд для тех, кто уже пришёл.

## 2. Масштаб: за две инфра-недели CF выставила вертикаль целиком
**Компьют:** Sandboxes GA — у агентов свои компьютеры (shell, ФС, процессы, старт по требованию); Containers стартуют ~6x быстрее со снапшотами; Workflows держит 50 000 concurrency; Artifacts — git-хранилище для десятков миллионов репо агентов; Durable Object Facets — каждой AI-сборке своя SQLite.
**Глаза и руки:** Browser Run — Live View, human-in-the-loop, CDP, записи сессий; Kitesurf — браузер целиком на Workers, с WebMCP.
**Память и знание:** Agent Memory — managed постоянная память; AI Search GA — поиск по пикселям изображений (не по капшенам), OCR сканов PDF, файлы до 10 MiB, гибридный retrieval; модели 14+ провайдеров одним биндингом.
**Деньги:** Monetization Gateway — «paywall для агентов» через HTTP 402, расчёты USDC (x402, Base), пер-запрос/per-token; Pay Per Use — паблишеру платят за каждое использование контента.
**Безопасность:** Mesh (scoped-доступ агентов к приватным БД без туннелей), non-human identities (GA), Managed OAuth для Access, MCP governance, Threat Signals бесплатно каждому аккаунту.
**Интерфейс:** cf CLI на ~3000 операций, Agent Lee (дашборд → один промпт), кодинг-агенту автоматически уходят стек-трейсы прод-фейлов — открывает PR сам.

## 3. Удобство (наши проверенные точки входа)
- WebMCP: один тумблер в дашборде — сайт начинает отдавать агентам функции (searchFlights() вместо симуляции кликов)
- Monetization Gateway: «несколько кликов» + правила цены на любые части запроса; расчёты и ретраи — на CF
- Threat Signals: включается бесплатно в дашборде, WAF-правила тянутся из парсинга threat-репортов сами
- Agent Lee: промпт вместо табов; Registrar API — регистрация домена из терминала агента
- У нас в хозяйстве: зоны на CF + cloudflared-туннели работают сами; WAF режет ботов без нашего участия. WebMCP и Threat Signals — два тумблера, до которых ещё не дошли руки — потому и ценность удобства проверяема: если включение действительно один клик, это последний барьер

## 4. Кульминация
Компьют → память → браузер → деньги → безопасность → интерфейс. Все шесть слоёв у одного вендора, и главный дизайн-принцип — «включается тумблером, платится за использование». CF не спрашивает, настанет ли эра агентов: она уже выставила счёт агентам за доступ к твоему сайту (402) — вопрос лишь, дашь ли ты себе попасть в её витрину.

## 5. Инсайт
Единственный слой, который CF НЕ автоматизирует за тебя — последний тумблер. И это фича: human-in-the-loop в Browser Run, scoped-токены вместо пароля админа, egress-прокси. Инфраструктурный оптимизм с встроенным тормозом — мы живём ту же модель на своём пайплайне.

## 6. Пометки честности
«Агенты >50%», «~6x», «22% Unweight» — заявления CF; Wallets/OS — waitlist. Проверено чтением блогов целиком + журнал Researcher.
