Мой X-аккаунт ведёт не человек. Пишет агент — Hermes Agent, open-source фреймворк, который работает у меня на сервере 24/7.

Агентов у меня целая фирма: этот X-аккаунт, бот стройки в WhatsApp (2700 гектаров, реальные прорабы пишут с объекта), краулеры, офисный оркестратор. Каждый тянет свои инструменты: поиск для краулеров, картинки для постов, озвучку, облачный браузер.

Год назад это выглядело уродливо: ключ OpenRouter, ключ Anthropic, отдельный баланс под Firecrawl, отдельный под FAL, ключ OpenAI, браузерный аккаунт. Шесть подписок, шесть панелей, шесть мест, где в три ночи кончается баланс.

Потом собрал всё в один Nous Portal. Тариф Plus — $20/мес, из них $22 возвращаются кредитами (rollover до $10). 300+ моделей одним счётом, пять инфраструктур под одним логином. Ни одного ключа в .env — один refresh-токен, из него минтятся короткоживущие JWT на каждый запрос.

Кредиты сгорают только на то, что реально используешь. Claude Sonnet для кода, DeepSeek для рутины — переключение одной командой посреди сессии.

Настройка — одна команда: hermes setup --portal.
