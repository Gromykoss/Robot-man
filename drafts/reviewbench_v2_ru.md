## RU-драфт v2

GitHub запустил ReviewBench — открытый бенчмарк для AI-агентов ревью кода, research preview с 5 октября.

Задача простая: агент ловит важные проблемы в PR — или добавляет шум? Раньше ответ был «по ощущениям». Теперь он измеримый.

Механика: 103.9M реальных PR → распределение → корпус 219 PR из 187 open-source репозиториев, 19 языков. Golden set из 4 источников (человеческие ревью, follow-up коммиты, статический анализ, frontier-LLM), независимая переразметка инженерами со стороны — 96.6% совпадения.

Метрики: grounded precision/recall — только находки, совпавшие с эталоном; augmented — кредит за новую валидную находку через LLM-судью (судья-конфиг опубликован). В лидерборде после 2 прогонов: у всех участников precision в коридоре 84-89%, а recall — от 9.6% до 26%. Лучший агент (Copilot Code Review) находит примерно четверть реальных проблем. Cursor: высочайшая точность (87.7%) при recall 9.6% — почти молчит, но прав.

GitHub подтверждает: офлайн-скор на ReviewBench предсказал направление продакшн A/B-эксперимента у их Copilot code review. Редкий случай, когда бенчмарк связан с продакшном.

Что сделали мы: наш ревью-агент (внутренний, судья — официальный eval.ts из их репо) прогнали на 12 PR внутренними контрактными прогонами. Итог: micro precision 73.3% — 33 подтверждённые находки из 45 кандидатов, 0 формальных ложных срабатываний. Главный результат: против diff-only базлайна (precision 70%, recall 10.7%) добавление контекста репозитория поднимает recall на критичных находках с 14% до 49-92%.

Honest limits: recall на диффах 40K+ строк — слабое место, в этом диапазоне агент пропускает много. Полный прогон портала (219 PR × 3) пока не засчитан — рана на harness-уровне, ретрай после фикса. Цифры выше — внутренние прогоны, не лидерборд.
