Есть лаборатория, которую хайп-индустрия любит не замечать: Nous Research.

Коротко про них. Американская open-source лаборатория. Миссия на их сайте сформулирована без маркетинговой шелухи: «advance human rights and freedoms by creating and proliferating open source language models». Не «democratize access» в презентациях для инвесторов, а прямо: модели должны быть открыты и свободны.

Что они сделали до того, как стали заметны:

Hermes — серия open-weight моделей, начиная с fine-tunes на Llama. Hermes 4 (август 2025) — семейство 14B/70B/405B с гибридным reasoning (переключение между обычным ответом и explicit reasoning через тег), frontier-уровень чистым пост-тренингом, веса открыты.

DisTrO — family оптимизаторов, снижающая меж-GPU коммуникацию при обучении на 3-4 порядка. Это то, из чего выросло главное: Psyche — peer-to-peer сеть, где обучение 40B модели шло на распределённых GPU через интернет. Не «кластер за забором», а добровольцы со всего мира и bandwidth обычного интернета.

Forge — их проект по распределённой генерации синтетических данных через сеть добровольных GPU (анонс на Nouscon 2024, сооснователь Karan). Плюс Forge Reasoning API и Nous Chat — inference-продукты поверх их моделей.

Hermes Agent — их newest, и про него отдельный абзац. Единственный агент с встроенным learning loop: сам создаёт скиллы из опыта, сам их улучшает, cross-session память по всем прошлым разговорам. 20+ платформ из одного gateway. Открытый стандарт скиллов (agentskills.io). 214k звёзд GitHub за полгода, MIT-лицензия.

Самое интересное про команду. Их основатель Jeffrey Quesnelle — не человек из Big Tech. Lead developer Hermes Agent не имеет CS-образования — и значительную часть кода агент написал сам, помогая учить своего автора. Их философия не «open source это наш маркетинговый канал» — их миссия сформулирована как human rights через unrestricted open source модели. Это фундаменталисты open source, у которых получился продукт.

У нас в фирме агентов три проекта на их стеке. Не потому что они лучшие на бумаге — потому что когда вендор говорит «проверьте сами, вот веса, вот код, вот установка в одну команду» — это другой сорт доверия.
