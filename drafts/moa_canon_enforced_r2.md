## Текст (`canon_enforced_20261025_v1_en.txt`)

**Хук — 8/10.**
"Everyone is writing rules files for their agents. Almost nobody is enforcing them." — контрастная антитеза, обобщающая боль всей аудитории (у каждого с ИИ-агентом есть CLAUDE.md/AGENTS.md). Останавливает: читатель узнаёт себя в первой же строке. Первые 160 символов укладываются в хук + первый абзац. Минус балл: тема «rules files» уже сильно изношена в нише — хук хорош, но не уникален по форме (тысячи постов начинаются с «everyone does X, nobody does Y»).

**Share-ability — 7/10.**
Пересылаемое ядро есть: «Rules loaded into context are a request. Rules checked by code are a contract» — цитируемая афористичная пара. Секция «What to steal» с тремя конкретными шагами (exit code, journal, monthly purge) — классический save/send-блок. «If the answer is "nothing", the rule is a wish» — вторая пересылаемая фраза. Минус: пост длинный (~2900 знаков), в X длинные тексты пересылают реже, чем режут в цитаты; длина съедает часть share-потенциала.

**Discussability — 8/10.**
Материала для спора достаточно: (1) тезис «git hook вместо доверия модели» — прямая провокация для лагеря «просто напишите правила лучше»; (2) «delete rules nothing enforces» — конфликтует с общепринятым «аккумулируйте знания в rules file»; (3) спор о том, что enforcement-слой — это костыль против плохих моделей или зрелая практика. Плюс встроенный кредит чужой статье (@cyrilXBT) — вежливая точка входа для ответной ветки автора. Минус: пост сам даёт сильные контраргументы заранее («not out of malice»), немного гася градус.

**Аутентичность — 8/10.**
Личный инцидент есть и конкретен: routine commit → spec drift одна строка → silent failure → git hook с intent-логом и SHA в versioned journal, exit 2 как у eval gates. Это не шаблон «я попробовал X, вот выводы» — детали (exit 2, journal, drift intent) верифицируемы в репо и уникальны. Минус: структура (hook → aphorism → what to steal) — узнаваемый формат ниши; финал «Building in public 🤖» — шаблонный.
