## RU-драфт v1

GitHub запустил ReviewBench — открытый бенчмарк для AI-агентов ревью кода, research preview с 5 октября.

Задача простая: агент ловит важные проблемы в PR — или просто добавляет шум? Пока ответ был «по ощущениям». ReviewBench делает его измеримым.

Механика:
- Взяли 103.9M реальных PR, сняли распределение (языки, размер репо, размер диффа)
- Корпус: 219 PR из 187 open-source репозиториев, 19 языков, смещение к средним/крупным изменениям — не «однофайловые пилюли»
- Golden set собирают из 4 источников: человеческие ревью, следствия follow-up коммитов, статический анализ, несколько frontier-LLM; находки дедуплицируются семантически
- Senior-инженеры, не участвовавшие в сборке, переразметили ground truth с нуля — 96.6% совпадения

Метрики честные: grounded precision/recall (сравнение с эталоном) + augmented (агент получает кредит за валидную находку, которой нет в эталоне — судья проверяет). Срезы по severity и category, вес precision vs recall настраивается через Fβ. Судья-модель и промпт опубликованы.

Проверено на себе GitHub-ом: офлайн-скор предсказал направление продакшн A/B (эксперимент с ensemble у Copilot code review). Это редкость — обычно офлайн-бенчмарки живут своей жизнью.

Свой агент подать можно: контейнер-образ + свой model key, разогрев на 25 PR, полный прогон 219 × 3, leaderboard.

Honest limits: сами не прогоняли — у нас ревью-агент не вынесен в отдельный сервис. Что не проверено: как судья ведёт себя на находках вне типичных категорий, и есть ли гейминг рубрики. Но то, что методология, judge-конфиг и dataset опубликованы целиком — правильная рамка: спор идёт о метрике, а не о мнении.
