## Текст RU

Часть 1 была **пилотом**: один live-контур — construction-site WhatsApp-бот.
148 markdown-файлов → contract index. Идеи OpenSpec (@0xTab) взяли в духе — не «поставили CLI и хаос кончился».

### 1) Пилот

На одном боте зафиксировали, что работает:
- короткий вход на сессию вместо «прочитай все docs»;
- deep docs только по маршруту карточки;
- после правки домена — обновить индекс или явно `not needed`.

Пилот доказал паттерн на одном репо.

### 2) Масштаб на всю команду

Те же правила вынесли **за пределы пилота** — на весь флот агентов:
- у каждого профиля — свой AGENTS и точка входа;
- deep docs — по маршруту (карточка / индекс);
- изменения домена — обновить индекс или `not needed`;
- орг как система: человек → оркестраторы → отделы + боты + инфраструктура.

### 4) Рецепт

Что реально стоит за каждым шагом — по нашим файлам.

**Boot-файл.** Один markdown, ~50 строк, читается на старте ВМЕСТО больших доков. Структура:
- `Purpose` — 2 строки, что делает система;
- `Boot Rule` — «читай только этот файл, глубокие доки открывай по маршруту»;
- `Global Invariants` — короткий список жёстких фактов (канон числа таблиц, approval на прод-send, таймзона);
- `Domain Map` — таблица: домен → карточка → источник → код → тесты → соседи риска;
- `Change Routing` — «задача про X → читай Y»;
- `Spec Drift Gate` — правило внизу файла.

**Domain cards.** Отдельные файлы `openspec/specs/<домен>.md`. В карточке: роль, владельцы, ловушки, GIVEN/WHEN/THEN. Правка домена = правка карточки, не переписывание «мира».

**Граф.** `knowledge_graph/graph.json`. Не рисуется руками — генерится из фактов системы. Узел = `["id", {"type": "..."}]`, ребро = `{"source", "target", "predicate", "source_file", "confidence"}`. Типы узлов: события, баги, фиксы, таблицы БД, компоненты бота, сервисы, шаблоны, решения, задачи. Граф читается, а не только показывается.

**Graph-view.** Из графа выгружаются заметки с `[[wikilinks]]` + canvas + `GRAPH INDEX` (оглавление по типам: боты, таблицы, баги, фиксы — кликабельно).

**Живой цикл.** Пересборка графа по расписанию (у нас каждые 6ч) + gate: после правки домена — обнови граф/карточку или явно `index update: not needed`. Дрейф ловится сверкой числа с git, а не «показалось».

**Флот.** Одна diagram-as-code схема (`Agent Fleet.d2`), рендер D2+ELK. У каждого блока — живая ссылка на AGENTS профиля.

**Критерий готовности.** Новая сессия агента стартует с boot-файла и карты, а не с «прочитай 148 файлов».

**Честный минус.** Без пересборки и gate граф гниёт так же, как md-свалка. Boot-файл, который не читают на старте, — просто ещё один md.

Документация, которую не видно, почти не существует.  
148 файлов → boot-файл + карточки → общий режим на флоте → граф и схема, где узел открывается.
