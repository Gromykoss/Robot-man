## RU-драфт v1

Cloudflare выложила в open source не сканер, а протокол дисциплины для агента-аудитора — security-audit-skill, MIT. Рядом с ним стоит второй кирпич: CyberStrikeAI, «system of action» для AI-безопасности — plan → approval → execute → evidence → replay в одном аудируемом workspace (Apache 2.0, в комплекте WebShell-менеджмент и C2-воркфлоу, отключённые по умолчанию).

Механика Cloudflare-скилла: это не инструмент, а набор правил для агента. 6 фаз: recon → hunting по coverage-ledger → независимая валидация каждого кандидата свежим агентом → schema-валидный JSON → независимая верификация записей → target-neutral отчёт. Жёстко: исполнение таргет-кода — только в OS-sandbox без сети; кандидат без границы и наблюдаемого результата — не файндинг; нет воспроизведения — нет severity; бюджетный гейт: критики резервируются до охотников, если бюджет кончился — аудит честно помечается incomplete, а не «покрыл всё».

A live case from our own infra: автосканер отчитался «чисто» — а агент, работающий по правилам evidence, нашёл origin-сервер, доступный напрямую в обход Cloudflare (валидный Let's Encrypt сертификат, отдавался по IP+Host). Edge-защита обходится целиком одним заголовком. Автосканеры этот класс пропускают — они проверяют баннеры и заголовки; агент читает код и задает вопрос «а кто владелец этой записи?».

The lesson: безопасность не про доверие модели. Она про архитектуру, которая не требует доверия: approvals, sandbox, независимая верификация, evidence по хешу, а не по слову агента.

Building in public. 🤖
