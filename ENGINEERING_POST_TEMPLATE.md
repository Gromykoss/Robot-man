# Шаблон инженерного поста @RobotsTJ500 (выведен из WebMCP + tailcat кейсов, 01-02.09.2026)

Утверждённый стиль: «спокойный инженерный отчёт». Структура и тон — от Сергея.

## Структура (соблюдать порядок)

1. **Хук — связь с серией + суть одной строкой.**
   - Если пост продолжает дугу «интернет агентов» — continuation hook: «WebMCP let agents talk to websites. tailcat lets them wire their machines together».
   - Хук = конфликт/важность/результат, НЕ пересказ доков и НЕ «я — агент, другой агент...»
2. **Что узнали** — суть инструмента/события одной строкой + @mentions официальной страницы и автора (верифицировать хендлы /2/users/by/username ДО драфта).
3. **Как работает** — механика списком: «что осталось / что выброшено», адрес-токен, hand-shake. Гуглимые строки ошибок = закладка для инженера.
4. **Когда применять** — сценарии из первоисточника + личный use case автора, если есть.
5. **Собственный опыт** — деплой, цифры (только из факт-таблицы брифа), негативные тесты, цитаты логов. Одна честная ошибка с уроком (если была) — сильнее идеальной картинки.
6. **Честные минусы + сравнение с альтернативами** (если релевантно: iroh и т.п.) — транспорт/форма/экосистема/релеи.
7. **Вывод** — связь с большой дугой («каждый убранный человеческий привратник = кирпич в интернете агентов»).
8. Финал одним сплошным блоком: «Building in public. 🤖» — **без хештегов** (канон 05.09: теги для обычного поста ≈0 / вред; см. `research/x_hashtags_2026_sergey.md`). 0–1 тег только по явному ok + живая лента события/сообщества.

## Анти-попа чеклист (каждая фраза = «факт или продажа?»)

- ❌ метафоры-штампы («тёмный лес», «potholes»), слоганы-хуки («one switch, zero code»)
- ❌ драматизация переходов, футуризм («ляжет в браузер» → «живёт в браузере»)
- ❌ антропоморфизм, идиомы, оценки без замера («takes five minutes» — только если посчитано)
- ❌ ALL CAPS в хуке (триггер спам-фильтра)
- ❌ self-reply, URL в теле (репо — только если это герой поста), выдуманные детали
- ❌ «honest» ×3 в одном тексте (слово-тик)

## Голос

- First-person «I/we» (агент = аккаунт), technical, no emojis кроме финального 🤖
- EN финал; RU-перевод для чтения Сергеем отдельно
- До 4000 знаков (note_tweet), не резать ценное, не лить воду

## Обложка (joint с текстом — прогонять парой)

- Идею согласовать с Сергеем ДО генерации; метафора = ось поста, не побочная ассоциация
- Сцена с героем/действием/свечением, не типографика («кто такую обложку заметит»)
- Тёплые тона/Pixar — по запросу; мрачный дефолт не автоматом
- Объекты целиком в кадре (обрезанные края = «фрагмент большой картины»), завершённая диорама. ⛔ Референс-обложка от пользователя = использовать ЕЁ (кроп/перегенерация ломают сцену: срезы персонажей — повторяющийся промах 01-02.09)
- Текст на обложке: PIL надёжнее AI-генерации; текст в кавычках только тот, что проверен посимвольно
- Финальный файл после кропа проверять vision отдельно (кроп режет: кейс 02.09 — 6-7 зон)
